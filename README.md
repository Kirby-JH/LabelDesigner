# 라벨 디자이너

엑셀/CSV 데이터를 불러와 **라벨 서식을 직접 디자인**하고, **롤 라벨(연속 용지)** 또는 A4 시트 라벨에
행마다 내용이 바뀌는 라벨을 인쇄하는 웹 페이지입니다.

### 바로 사용하기 → **<https://kirby-jh.github.io/LabelDesigner/>**

## 실행

위 주소로 바로 쓰거나, 저장소를 내려받아 `index.html`을 더블클릭해도 똑같이 동작합니다.
서버·빌드 과정이 없고, 라이브러리까지 모두 포함되어 있어 오프라인에서도 쓸 수 있습니다.
입력한 데이터는 브라우저 밖으로 나가지 않습니다.

```
git clone https://github.com/Kirby-JH/LabelDesigner.git
# 또는 Code → Download ZIP 받은 뒤 index.html 열기
```

## 구성

## 1. 데이터

- **붙여넣기** — 엑셀에서 셀 범위를 복사해 붙여넣기 (탭/쉼표 자동 인식)
- **파일** — `.xlsx` `.xls` `.csv` `.txt` 드래그 앤 드롭. 시트가 여러 개면 선택.
  CSV는 UTF-8 / EUC-KR(CP949)을 자동 판별합니다.
- **수량 열**을 지정하면 그 수만큼 같은 라벨이 반복됩니다. `반복 배수`는 전체에 곱해집니다.
- `디자인 화면에 미리 볼 행`으로 편집 중에 어떤 행의 값을 볼지 고릅니다.

### 데이터 확인
`표로 확인` 버튼을 누르면 읽어들인 데이터가 표로 펼쳐집니다. 행을 클릭하면
그 행이 디자인 화면의 미리보기 값이 됩니다. 표에서는 이렇게 표시합니다.

- **빨간 행** — 바코드 요소에 들어갈 값이 그 규격에 맞지 않거나 비어 있음
- **주황색 행 번호** — 앞선 행과 완전히 같은 중복 행

바코드 형식 오류는 인쇄하기 전에 데이터 패널에 몇 행인지 요약해 줍니다.

검사와 표는 **지금 출력하려는 범위를 따라갑니다.** 출력 범위를 `15,000~15,500행`으로
옮기면 그 구간을 검사하고 표에도 그 구간이 보입니다. 수만 행짜리 시트에서도
실제로 뽑을 부분을 확인할 수 있습니다. (한 번에 검사 2,000행, 표 200행, 미리볼 행 300행)

## 2. 용지

### 롤 라벨 (기본)
연속 용지에 한 줄로 출력하는 방식입니다. **라벨 1장 = 인쇄 1페이지**로 내보내며,
인쇄 페이지 크기는 `라벨 세로 + 라벨 사이 간격`이 됩니다.

- 프리셋: 30×20 / 40×20 / 40×30 / 50×30 / 50×40 / 60×40 / 70×50 / 80×50 / 90×30 /
  100×50 / 100×75 / 100×100 / 100×150(택배 송장) / 영수증 롤 58·80mm 폭
- `인쇄 방향` 0° / 90° / 180° / 270° — 프린터가 라벨을 눕혀 먹일 때 사용합니다.
  90°·270°에서는 인쇄 페이지의 가로·세로가 자동으로 바뀝니다.
- 프린터 드라이버의 용지 크기도 같은 치수(간격 포함)로 맞추세요.

### 시트 라벨 (A4 칸 용지)
A4 한 장에 칸이 나뉜 라벨지입니다. 프리셋(65·40·27·24·21·18·16·14·12·10·8·6·4·2·1칸) 또는
열·행·라벨크기·간격을 직접 입력합니다. 여백은 격자를 용지 가운데에 놓도록 자동 계산됩니다.
`시작 칸 번호`로 쓰다 남은 용지의 N번째 칸부터 이어서 인쇄할 수 있습니다.

`인쇄 보정 ↔ ↕`는 프린터마다 조금씩 밀리는 출력을 맞추는 값입니다.

### 출력 범위
수만 행짜리 시트를 넣어 두고 **필요한 구간만** 뽑습니다. 기준을 둘 중에 고릅니다.

- **데이터 행 번호** — `1,001~1,500행`처럼 엑셀에서 보던 행 번호 그대로. 데이터 표의 `#` 열과 같습니다.
- **라벨 장수** — 수량을 펼친 뒤의 장수 기준. 용지가 걸려서 `237장`부터 다시 찍을 때 씁니다.

범위를 바꾸면 `전체 30,000행 중 1,001~1,500행 → 라벨 1,023장` 처럼 바로 환산해 보여 줍니다.
**일련번호는 원래 순서를 그대로 이어 갑니다** — `1,001행`부터 뽑아도 그 라벨의
`{일련번호}`는 1이 아니라 앞 구간까지 합한 번호입니다.

한 번에 5,000장까지 만들고, 넘으면 범위를 나누라고 안내합니다. 3,000장이 약 90초,
5,000장이 약 250초 걸리니 `500~1,000장`씩 끊어 뽑는 쪽이 훨씬 빠릅니다.

`길이 단위`를 인치로 바꾸면 모든 길이 입력칸이 인치로 표시됩니다.
값은 내부적으로 mm로 보관하므로 단위를 오가도 치수는 그대로입니다.

## 3. 요소 디자인

가운데 캔버스가 **라벨 1장**입니다. 요소를 끌어 옮기고, 모서리 손잡이로 크기를 바꾸고,
위쪽 둥근 손잡이(⟳)로 회전합니다. 좌표·크기·회전은 속성 패널에서 숫자로
정확히 입력할 수도 있습니다 (길이는 현재 선택한 단위, 회전은 도).

끌어 옮기는 동안 **라벨의 가장자리·중앙과 다른 요소의 변·중심에 자동으로 달라붙고**
맞춰진 기준선이 표시됩니다. Alt를 누르면 꺼집니다.

**여러 개를 한꺼번에** 다룰 수 있습니다. Shift+클릭으로 더하거나 빼고, 빈 곳을 끌면
범위 선택, Ctrl+A로 전체 선택, Esc로 해제. 여러 개를 고르면 속성 패널이
**가로/세로 정렬과 균등 분배**로 바뀌고, 끌면 함께 움직입니다.

| 단축키 | |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z | 실행 취소 / 다시 실행 (60단계) |
| 방향키 / Shift+방향키 | 0.2mm / 1mm 이동 |
| Ctrl+D | 복제 |
| Delete | 삭제 |
| Ctrl+A / Esc | 전체 선택 / 선택 해제 |
| Alt (드래그 중) | 정렬 가이드 끄기 |
| Shift (크기 조절 중) | QR 정사각 유지 |

| 요소 | 설정 |
|---|---|
| **텍스트** | 내용(고정 문구 + `{열이름}` 혼용), 글꼴, 크기, 줄간격, 자간, 색, 가로/세로 정렬, 굵게/기울임, 자동 줄바꿈, **세로쓰기**, **상자에 맞게 자동 축소** |
| **QR** | 내용, 오류 보정 L/M/Q/H, 여백(모듈), 색 |
| **바코드** | 내용, 종류(CODE128/128B/128C, EAN-13/8, UPC-A, CODE39, ITF, ITF-14, MSI, Codabar, Pharmacode), 숫자 표시, 글자 크기, **좌우 여백(quiet zone)**, 색 |
| **도형/선** | 채우기, 선 색·굵기, 모서리 둥글기 (세로를 얇게 하면 구분선) |
| **이미지** | 로고 등 이미지 파일 삽입, 비율 유지/채움/늘리기. 경로에 `{열이름}`을 쓰면 행마다 다른 그림 (예: `img/{품번}.png`) |

### 고정 텍스트와 가변 데이터
내용에 `{열이름}`을 쓰면 행마다 값이 바뀌고, 나머지 글자는 그대로 인쇄됩니다.
예) `가격: {가격}원`, `https://shop.example.com/p/{바코드}`
머리글이 없으면 `{1}` `{2}` 처럼 열 번호로도 쓸 수 있습니다.

데이터 열 말고 **내장 변수**도 쓸 수 있습니다.

| 쓰는 법 | 결과 |
|---|---|
| `{일련번호}` | 출력 순서 1, 2, 3 … |
| `{일련번호:0001}` | `0001` 부터 4자리로 (시작값과 자릿수를 함께 지정) |
| `{행번호}` | 데이터 행 번호 — 수량만큼 반복돼도 같은 행은 같은 번호 |
| `{오늘}` · `{오늘:YY.MM.DD}` | 오늘 날짜 |
| `{시간}` · `{시간:HH:mm:ss}` | 현재 시각 |

값 뒤에 `|`를 붙여 **가공**할 수 있습니다. 여러 개를 이어 붙일 수도 있습니다
(`{가격|곱하기:1.1|소수:0|천단위}`).

| 쓰는 법 | 결과 |
|---|---|
| `{입고일\|날짜}` | 날짜 부분만 → `2025-10-04` |
| `{입고일\|날짜:YY.MM.DD}` | `25.10.04` · `M월 D일` 등 원하는 형식으로 |
| `{입고일\|시간}` · `{입고일\|시간:HH:mm:ss}` | 시간 부분만 → `14:30` / `14:30:00` |
| `{바코드\|ean13}` | 체크디지트를 계산해 붙임 (`880123456789` → `8801234567893`) |
| `{가격\|천단위}` | `12500` → `12,500` |
| `{코드\|앞:4}` · `{코드\|뒤:4}` | 앞/뒤 N글자 |
| `{품명\|자르기:3,5}` | 3번째 글자부터 5글자 |
| `{품명\|치환:제주>한라}` | 찾아 바꾸기 |
| `{수량\|채움:0000}` | `150` → `0150` |
| `{가격\|곱하기:1.1}` · `빼기` · `더하기` · `나누기` | 사칙연산 |
| `{값\|소수:2}` | 소수 자릿수 맞추기 |
| `{코드\|숫자}` · `대문자` · `소문자` · `공백제거` · `다듬기` | 문자 정리 |

날짜는 `25.10.04`, `2025-10-04`, `2025/10/4`, `20251004`, `2025년 10월 4일`,
`10.04`, `25.10`, 엑셀 날짜 일련번호까지 알아서 읽습니다.

**시각은 콜론(`14:30`)이나 한글(`9시30분`)로 적은 것만 읽습니다.**
점(`.`)으로 끊긴 숫자는 언제나 날짜로 봅니다 — `25.10.04 14.30.00`처럼
날짜 뒤에 점으로 붙어 있어도 뒷부분을 시각으로 보지 않습니다.
시각까지 쓰려면 `25.10.04 14:30:00`처럼 콜론으로 적어야 합니다.

| 값 | `\|날짜` | `\|시간` |
|---|---|---|
| `25.10.04 14:30:00` | 2025-10-04 | 14:30:00 |
| `2025-10-04 14:30` | 2025-10-04 | 14:30:00 |
| `25.10.04 14.30.00` | 2025-10-04 | — (점은 시각이 아님) |
| `25.10.04` · `12.11.10` | 2025-10-04 · 2012-11-10 | — |
| `14.30.00` | — | — |
| `14:30:00` · `9시30분` | — | 14:30:00 · 09:30:00 |
| `10.04` | 올해 10월 4일 | — |
| `25.10` | 2025년 10월 (일은 1일) | — |
| `45934.604166` | 2025-10-04 (엑셀 일련번호) | 14:30:00 |

두 토막짜리는 `1~12.1~31`이면 **월.일**(연도는 올해), `13~99.1~12`면 **연.월**(일은 1일)로
봅니다. 숫자만 있는 값은 `32874~54788`(`1990~2050`) 범위일 때만 엑셀 일련번호로 보므로,
수량 `150`이나 가격 `12500`에 `|날짜`를 걸어도 날짜가 되지 않습니다.

### 조건에 따라 다르게 찍기

```
{?수량>100}대량{:}소량{/}        수량이 100보다 크면 "대량", 아니면 "소량"
{?비고}({비고}){/}               비고가 비어 있지 않을 때만 괄호 붙여 출력
{?등급=A}★★★{:}★{/}             거짓 쪽({:} 이하)은 생략할 수 있습니다
{?품명 포함 우유}냉장{/}           포함 · 시작 · 끝 도 씁니다
```

쓸 수 있는 연산자는 `=` `!=` `>` `<` `>=` `<=` `포함` `시작` `끝` 이고,
연산자를 안 쓰면 **값이 비어 있지 않으면 참**입니다.
양쪽 다 숫자면 숫자로, 아니면 글자로 비교합니다. 조건 안에 조건을 넣어도 됩니다.

### 요소 잠금
요소 목록의 자물쇠 버튼을 누르면 그 요소는 캔버스에서 집히지 않습니다.
배경 도형이나 고정 문구가 자꾸 선택되는 걸 막을 때 씁니다. 잠금 해제도 같은 버튼으로 합니다.

### 서식 라이브러리
상단의 서식 칸에서 디자인과 용지 설정을 **이름 붙여 여러 벌** 보관하고 골라 쓸 수 있습니다.
`저장`으로 현재 상태를 담고, 목록에서 고르면 바로 적용되며, `삭제`로 지웁니다.
다른 PC로 옮기거나 백업할 때는 `파일↓`로 `.json`을 내려받고 `파일↑`로 가져옵니다.
작업 중인 내용은 브라우저에도 자동 저장되어 다시 열면 유지됩니다.

## 화면 크기

1000px 이하에서는 좌우 패널이 서랍으로 바뀌어 캔버스가 화면 전체를 씁니다.
상단 좌측 `☰`(데이터·용지)와 우측 `▦`(속성) 버튼으로 열고 닫습니다.
태블릿에서도 쓸 수 있습니다.

## 4. 인쇄

`🖨 인쇄 / PDF` 버튼(또는 Ctrl+P). 치수를 정확히 맞추려면 인쇄 대화상자에서:

- **여백: 없음**
- **배율: 100%** (`크기에 맞춤` 해제)
- **배경 그래픽: 켬**

일반 용지에 시험 인쇄해 라벨지와 겹쳐 보고, 어긋나면 `인쇄 보정` 값으로 맞추세요.
바코드는 스캐너 인식을 위해 좌우 여백(기본 10모듈)을 0으로 줄이지 마세요.

## 알아 둘 점

- **무거운 파일은 필요할 때만 받습니다.** 엑셀 파서(gzip 308KB)는 `.xlsx`를 실제로 열 때,
  내장 글꼴은 그 글꼴을 실제로 쓸 때 내려받습니다. 글꼴은 한글 11,172자를 전부 담되
  자주 쓰는 2,350자(KS X 1001)와 나머지를 쪼개 두어, 보통은 345KB만 받습니다.
- **자동 저장이 실패하면 알려 줍니다.** 이미지 요소를 많이 넣으면 브라우저 저장 공간
  한도를 넘길 수 있습니다. 그때는 경고가 뜨니 상단 `파일↓`로 `.json`을 내려받아 두세요.

  등을 고르면 그 PC에 설치된 글꼴을 쓰고, 그때는 PC마다 모양이 달라질 수 있습니다.

한글 전체를 담되 인쇄에 필요 없는 힌팅·레이아웃 테이블을 덜어내고 서브셋했습니다.

## 검증 내역

헤드리스 Chrome으로 실제 인쇄 PDF를 만들어 측정·디코딩했습니다.

- 롤 60×40mm + 간격 2mm → 인쇄 페이지 59.94×41.99mm, 라벨 3장 = 정확히 3페이지
- 인쇄 방향 90° → 페이지 39.88×62.06mm로 자동 전환
- A4 시트 21칸 → 용지 209.9×297.0mm, 열 피치 66.0mm·행 피치 38.1mm (설계값 일치)
- 요소 좌표 실측: 구분선 x `5.00~55.03mm` (설계 `5~55`), QR 암부 `6.62~23.47mm` (설계 `6.6~23.4`)
- 출력된 QR 디코딩: 숫자 바코드·URL·한글 모두 원본과 일치
- 출력된 EAN-13 바 패턴을 95모듈 단위로 추출해 규격 인코딩과 **완전 일치** 확인
- 이동/크기조절/회전, 서식 JSON 왕복, 브라우저 재시작 후 복원 동작 확인
- 대량 데이터: 30,000행(780KB) 붙여넣기 정상, 항목 수집 20ms, 힙 23MB.
  `100~102행` 구간 출력 시 일련번호가 `199~204`로 이어지고 바코드도 해당 행과 일치
- 내장 글꼴: 보통 글자는 common 2개만 로드(345KB), 희귀 음절이 나오면 나머지 조각을
  추가 로드, 시스템 글꼴만 쓰면 글꼴 파일을 받지 않음.
  인쇄 PDF에 `Pretendard-Regular`/`Bold`가 서브셋으로 실제 임베드되는 것까지 확인
